# jogo21

Projeto Maven criado automaticamente com Java 25 e JUnit 5.

## Requisitos

- Java 25
- Maven

## Como compilar

```bash
mvn compile
```

## Como executar

```bash
chmod +x run.sh 
./run.sh
```

## Como executar os testes

```bash
mvn test
```

## Como gerar o pacote

```bash
mvn package
```
